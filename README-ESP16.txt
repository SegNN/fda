FDA ESP16 — аватарка в круге и найденные исходники героев

Сборка: весь FDA-ESP16 в НОВУЮ папку проекта -> build.bat.
Нужны MSVC x64, Desktop development with C++, Windows SDK. Готовой DLL нет.
Маркер сборки/меню ESP16. При ошибке не использовать старую DLL.
Файлы установленной игры при разработке не читались и не изменялись. GitHub не обновлён.

НОВОЕ В ESP:
Круг пропавшего врага теперь заполнен квадратной аватаркой из assets/heroes,
обрезанной настоящей круговой геометрией. На ней нет квадратных углов.
Обводка убывает за 10 игровых секунд, таймер находится СНИЗУ, чтобы не закрывать лицо.
Аватарка сохраняется вместе с полным handle и последней видимой мировой точкой;
скрытый новый снимок не меняет ни портрет, ни координаты. Все 127 каталоговых аватарок
проверены на наличие в комплекте. Если имя/текстура не разрешаются, нейтральный круг
с таймером вместо чужой выдуманной аватарки. Таймер/обводка продолжают работать.
По истечении 10s круг исчезает. При возвращении видимости исчезает сразу.
Камера перепроецирует сохранённую мировую точку. Пауза не расходует игровой таймер.
Полоса направления движения не возвращена. Видимые HeroInfo/HP/скиллы прежние.
Метка — история последнего наблюдения, НЕ текущая позиция врага в тумане.
Нужны определённый локальный игрок и читаемая штатная маска обзора; forced VBE выключен.
При unknown/observedOnly память не угадывает обзор и геройские данные не показываются.
Copy ESP diagnostics содержит team / visionRead / visionMask / forcedVBE.

НАЙДЕННЫЕ ИСХОДНИКИ:
В references/combo-sources/snapshots/ включены 201 текстовый upstream файл с MIT лицензиями:
- Eroica-cpp/dota2scripts: 43 Lua-скрипта (Invoker/Tinker/Axe/Armlet и другие) + notices/README.
- OpenHyperAI: 128 hero-файлов BotLib; соответствия есть для всех 127 героев FDA.
- zfael/dota2-scripts: выбранные Rust-модули героев/GSI + notices/README.
Это справочные СНИМКИ частей upstream проектов, не полный комплект их зависимостей.
Скрипты не запускались, не подключены к runtime FDA и не участвуют в build.bat.
COMBO-SOURCES.md — APIs, ограничения и план переноса.
COMBO-SOURCE-COVERAGE.json — точный файл/URL для каждого героя.
references/combo-sources/fetched-files.json — commit, source URL, размер, SHA256 каждого файла.
MIT licenses и исходные copyright/author comments сохранены. GPL/no-license исходники
только перечислены в исследовании, не скопированы и не связаны с проектом.
В неподключённых helper-модулях меню теперь указан справочный исходник этого героя.
НАЛИЧИЕ ФАЙЛА НЕ РАВНО РАБОЧЕМУ ПРОКАСТУ. Все автопрокасты в FDA НЕ реализованы.
Чужие Heroes/NPC/Ability API, GetBot/Action_UseAbility и Rust ActionExecutor несовместимы
с FDA без native adapter, hero-specific состояния и отдельных проверок.
Из Lua OnProjectile нельзя получить события снарядов, которых ещё нет в FDA.
Armlet алгоритм не менялся: нет нового предсказателя всего смертельного урона.

Проверки: 18 Linux mock/portable групп без ASan/UBSan. Фактические функции круга
скомпилированы и отрисованы на синтетических данных; портрет и таймер визуально проверены.
Проверены разные герои, сохранение имени после исчезновения, serial, некорректные имена,
10s/5s/expiry/reappearance/pause/unknown/death/time reset. Полная Windows/D3D11/live Dota
сборка и чужие автоматические скрипты НЕ проверены и не объявляются рабочими.
