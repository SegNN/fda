FDA ESP15 — изменения отображения и советник по составу

Распаковать весь FDA-ESP15 в новую папку ПРОЕКТА. Запустить build.bat.
Нужны Visual Studio Desktop development with C++, MSVC x64 и Windows SDK.
Маркер сборки/меню ESP15. Готовой DLL нет. Старую DLL при ошибке не использовать.
Файлы установленной игры при разработке не читались и не изменялись. GitHub не обновлён.
Это полный текущий комплект исходников, НЕ все функции Lotus и не готовый SDK Octarine.

ESP:
- Удалена полоса направления движения из DrawSkillPreview. Она раньше рисовалась без каста.
  Поддерживаемые отдельные индикаторы реального каста сохранены.
- Нормальный HeroInfo и enemy spell preview рисуются только при читаемой штатной маске
  видимости для своей команды. В тумане не остаются HP, предметы, скиллы и баффы героя.
  Скрытые подпортретные значения тоже не рисуются.
- При переходе видимый -> скрытый появляется круг на последней ПОДТВЕРЖДЁННО видимой
  позиции: число 10..1, убывающая обводка. Через 10 игровых секунд исчезает полностью.
  Это отметка истории наблюдения, НЕ реальная текущая позиция скрытого героя.
  Скрытая новая координата НЕ двигает круг. При возвращении видимости круг сразу убирается.
- Если ранее видимый объект исчез из снимка, начинает тот же 10s период памяти.
  Исчезновение из снимка может быть потерей чтения, не доказательством именно тумана.
- Время игровое: пауза не расходует таймер. Откат времени/смена команды сбрасывает память.
- Ранее не виденный герой не получает выдуманную отметку; прочитанная смерть её убирает.
  Ключ — полный handle с serial. Нечитаемая маска обзора = unknown, а не «враг скрыт».
- При unresolved local player / observedOnly геройские ESP и fog-memory не показываются:
  определить свою команду/нативный обзор достоверно нельзя. Остальные типы ESP не переделаны.
- cfg::vbe обязан быть false: legacy forced vision пишет в ту же маску и портит её смысл.
  Loader уже сбрасывает этот флаг. При его принудительном включении fog-memory отключается.
- Native HP текст и способности видимых героев остаются прежними. Это НЕ полный новый
  интерфейс, взятый из DLL: рабочий визуальный renderer Octarine полностью не восстановлен.
- Copy ESP diagnostics теперь содержит team, visionRead, visionMask, forcedVBE.

Проверка в демо:
ESP heroes включён, локальный игрок определён, forced VBE выключен.
Видимый враг -> ушёл в туман: только круг. Через 5s половина обводки, через 10s ничего.
Повторно появился: обычный HeroInfo без круга. Движение камеры перепроецирует сохранённую
мировую точку, а не оставляет экранный кружок на прежнем пикселе.
Если ничего не видно, прислать полный Copy ESP diagnostics в видимом и скрытом состояниях.
Смещения и смысл live visibility mask на конкретной версии Dota ещё требуют проверки.

Советник:
Меню Прочее / Misc -> Draft advisor.
Ручной ввод до четырёх союзных героев, пять рекомендаций с причинами по ролям.
Повторные союзные герои исключаются из выбора; выбранные герои не рекомендуются.
Каталог 127 героев: опубликованные Role/Rolelevels из имеющегося pinned KV snapshot.
DRAFT-ADVISOR-SOURCES.json содержит источники, SHA256 и описание эвристики.
Алгоритм дополняет покрытие ролей; при равной оценке порядок каталога алфавитный.
Это НЕ оптимальный матчап, мета, winrate, учёт линий/игроков/банов/врагов.
Нет чтения текущего драфта, нет автоматического пика; ввод не сохраняется в профиле.
Значит запрошенный полноценный «смотрит все союзные пики сам» здесь НЕ завершён.

Прокасты / Armlet:
Все геройские автоматические прокасты НЕ добавлены. Каталог не равен рабочим combo scripts.
Нет верифицированного order adapter, полного ability targeting/phase/cooldown/ownership
контракта и hero-specific сценариев. Нельзя выдавать PrepareUnitOrders псевдокод за это.
Armlet алгоритм ARM13/ARM14 НЕ менялся, исходники сверены по SHA256 с предыдущим комплектом.
Новых обещаний выживания/переключения под любым уроном нет; damage_probe диагностический.
Косметический GC по-прежнему отключён. Обход античита/авторизации не добавлялся.

Отдельно скомпилированы и отрисованы фактические функции fog-marker и draft-advisor UI.
Проверены 10s/5s/expiry/return/pause/unknown/death/serial/time reset, роли/фильтры/ранжирование.
Полная MSVC сборка, D3D11 и живой матч НЕ проверены. Это не гарантия работы в текущем клиенте.
