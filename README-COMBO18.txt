FDA COMBO18 — экспериментальные базовые прокасты внутри FDA, без Umbrella

СТАТУС: это промежуточный исходный проект, НЕ завершённый комплект всех героев.
Готовой проверенной Windows DLL нет. Windows-сборка и живая Dota не проверены.
Все найденные сторонние Lua/Rust скрипты целиком НЕ перенесены.

ДОБАВЛЕНО:
- Общий C++ исполнитель: цель фиксируется по полному handle/serial; один проход на
  удержание; следующий спелл только после cooldown подтверждения конкретного предыдущего.
  Phase/mana loss сами по себе не считаются подтверждением. 2s timeout, без повтора ввода.
- 9 подключённых базовых профилей (NOT full upstream scripts):
  Lion: Hex -> Earth Spike -> Finger of Death.
  Lina: Light Strike Array -> Dragon Slave -> Laguna Blade.
  Sven: God's Strength -> Storm Hammer -> Warcry.
  Vengeful Spirit: Magic Missile -> Wave of Terror.
  Ogre Magi: Fireblast -> Ignite.
  Zeus: Lightning Bolt -> Arc Lightning -> Thundergod's Wrath.
  Queen of Pain: Shadow Strike -> Sonic Wave -> Scream of Pain.
  Luna: Lucent Beam -> Eclipse.
  Dragon Knight: Dragon Tail -> Breathe Fire (консервативные 125 единиц).
- Huskar / Armlet сохранён отдельно, его алгоритм не менялся.
- Для каждого профиля сохраняются enable, activation bind и native spell keys.
  Подтверждение quickcast НЕ сохраняется; после загрузки профиля подтвердить заново.
- Проверки: собственный выбранный герой, цель/спелл identity, видимость, illusion,
  state/modifiers, cooldown/phase, mana, range, menu/focus/pause/owner, modifier/mouse buttons,
  channel/active ability и input lane. Перед вводом повторная проверка identity/owner/pause.
- При неизвестных/несогласованных данных ввод блокируется, guards не обходятся.

КАК ПРОВЕРИТЬ В ДЕМО:
1. Распаковать ВЕСЬ архив в новую папку ПРОЕКТА, НЕ в установленную папку игры.
   Запустить build.bat на Windows с MSVC x64 / Desktop development with C++ / Windows SDK.
   При ошибке сборки старую DLL не использовать. Это исходный проект без prebuilt DLL.
2. В меню «Помощники» выбрать свой профиль. Enable по умолчанию выключен.
   Назначить отдельный hold bind, не совпадающий со spell/menu/unload keys.
   Проверить каждую native клавишу в Dota: quickcast НА НАЖАТИЕ, соответствие нужному спеллу.
   Далее отметить подтверждение. Не отмечать его до проверки.
3. Для этих профилей выключить Armlet auto: пока он включён, он владеет input lane.
   Должен быть выбран только собственный герой. Закрыть чат, консоль и другие поля ввода:
   их состояние в игре этот адаптер НЕ распознаёт. Проверить в демо с видимой целью.
4. Все нужные спеллы должны быть изучены, готовы, с достаточной маной. Герой близко к цели:
   лимиты 125–500 зависят от профиля; автоподхода/Blink нет.
5. Навести курсор рядом с видимым врагом, закрыть FDA меню, удерживать hold bind.
   Один проход. После завершения/ошибки ОТПУСТИТЬ бинд; удержание не перезапускает цепочку.
   Статус показан в настройках профиля. Если блокируется — записать ТОЧНЫЙ статус.
6. Отдельно проверить отпускание до каста, недостаток маны, cooldown, потерю цели,
   pause, открытие меню и потерю фокуса. Модуль не должен продолжать поздний ввод.

ОГРАНИЧЕНИЯ:
- Подтверждение cooldown означает наблюдение расхода способности, НЕ попадание/убийство.
  Нативная клавиша не является exact-target engine order: игровой quickcast использует
  проекцию курсора. Возможны промахи/перехват цели на экране. Нет гарантии попадания.
- Нет item/Blink/BKB очередей, прогноза позиции/урона, delayed-stun hit confirmation,
  aspect/talent/Scepter/Shard стратегий, vector casts, каналов или сложных multi-unit механик.
- Invoker, Meepo, Arc Warden, Tinker, Earth Spirit, Rubick, Morphling и другие полные
  геройские сценарии НЕ добавлены как якобы рабочие. Для остальных 118 героев native
  последовательности отсутствуют. COMBO-SOURCE-COVERAGE.json содержит статус каждого.
- Static memory offsets не подтверждены на текущем живом клиенте. Читаемость/mock PASS
  не является доказательством live совместимости. Задача «все прокасты работают» НЕ выполнена.
- ASan/UBSan не запускались успешно: libasan.so.6 отсутствует в среде. Успешные проверки
  выполнены без санитайзеров. Это Linux mock tests, не Windows ABI/GPU/Steam/live Dota QA.
