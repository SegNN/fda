База GitHub: SegNN/fda / 40a11e81b0ba467b4980590d7a61dcfda01f87fe.

Цель патча: устранить/диагностировать Controller: missing -> Frame: invalid со скриншота.
Это НЕ подтверждённое полное исправление всех функций и не рабочий скинченджер.

Установка:
1. Полностью закрыть Dota со старой DLL. Не заменять DLL в работающем процессе.
2. Распаковать ЦЕЛИКОМ в НОВУЮ папку, не накладывать старые архивы/патчи.
3. Запустить build.bat. Нужны MSVC x64 и Windows SDK.
4. Использовать только DLL, полученную после успешной сборки.
5. В меню должна быть подпись FDA 0.5.5 / CTRL1.
   В Data diagnostics — Controller patch: CTRL1 / base 40a11e81.
   Если подписи нет, загружена другая DLL.
6. Проверять сначала в демо/локальном лобби с выбранным героем.
7. После 5-10 секунд сделать скрин Data diagnostics, включая новые строки.
   Если всё не помещается, прокрутить панель и сделать второй скрин.

Изменения:
- Используется глобальный указатель dwLocalPlayerController=0x6215E88 из опубликованного
  SegNN/dota2bud, build 987800-1dd56833b5086ae. Это кандидат, а не безусловно доверенный адрес.
- Проверяется указатель/vtable, известный тип C_DOTAPlayerController и локальный флаг.
- Если флаг=0, этот путь допускается только из выделенного local global и только при
  подтверждённой связи assigned hero, полном handle/serial и совпадении player ID/owner.
- У сканирования остаётся резервный путь. Несколько local-marked кандидатов не выбираются случайно.
- Перед построением Frame повторно проверяются тип героя, владение, координаты, команда/HP и время.
- Вместо один раз навсегда выбранной маски handle она проверяется по текущему контроллеру.
- Сканер сообщает проходы, heartbeat и исключения. После исключения — ограниченные повторные пуски,
  после трёх исключений он прекращает работу; ошибка остаётся в диагностике.
- Сохранены предыдущие исправления кэша: не кэшировать отрицательную классификацию,
  учитывать поколение/identity и отбрасывать устаревшие кадры.
- Matrix RVA и схема полей не заменены на выдуманные значения.
