FDA 0.5.5 / ESP4 — возврат штатного оформления

1. Закрой Dota и программу, использующую прежнюю DLL.
2. Распакуй ВЕСЬ архив в новую папку. Это исходники, не готовая DLL.
3. Запусти build.bat с MSVC x64 Desktop development with C++ и Windows SDK.
4. При успешной сборке результат build\obsdota2.dll. При ошибке не использовать старую DLL.
5. Проверь маркер FDA 0.5.5 / ESP4, сначала в демо/локальном лобби.

Изменения относительно ESP3:
- Диагностический рендерер убран из игрового экрана: никаких npc_dota_*, [Radiant]/[Dire],
  строк HP/MAX и принудительных дополнительных полосок HP.
- Теперь observed-only использует существующий hud::DrawWorldHero из проекта, как обычный режим.
- Штатная полоска игры не заменяется; Custom hero bars управляет существующей панелью HUD.
  По умолчанию hudWorld=false, то есть нет дублирующих кастомных полосок поверх штатной.
- Возвращены фиолетовые уголки вместо сплошных цветных прямоугольников. EspBoxes управляет рамкой.
- Для вардов используется прежняя компактная метка ward, не длинное техническое имя.
  Пока команда своего игрока неизвестна, WARD!! и дистанция до игрока не угадываются.
- Нижняя техническая надпись WORLD ESP удалена. Все сведения остаются в Data diagnostics.
- Announcer и killing-spree announcer исключены из Classify/IsHeroEntity/DetectMask.
  Они используют npc_dota_hero_* имена, но не являются игровыми героями.
- Рабочая проекция ESP3 сохранена; off-camera zero-origin не переворачивает Y.

Что ещё НЕ восстановлено:
В присланном отчёте controllers=0 и localFrame=0. Свой игрок пока неизвестен; автоматизация
остаётся отключена. В observed-only инвентарь/абилки/баффы/таймеры ещё не читаются,
поэтому предметы, значки способностей и кулдауны этим патчем НЕ восстановлены.
Косметика/GC отключены. Auto-accept без GC-сигнала недоступен.
При включении Custom hero bars HP/мана/уровень показываются штатной панелью проекта;
окраска команды в observed-only абсолютная Radiant/Dire, не "союзник/враг".

Проверки:
13 Linux mock/portable групп пройдены. Проверены фильтр дикторов, настоящие игровые герои,
угловые рамки ImGui, отключение рамок без принудительного debug текста/HP,
маршрутизация Hero/Ward/Roshan, регрессия присланной матрицы и защитные условия.
Тест маршрутизации НЕ проверяет реальный hud.cpp с D3D11/WIC/текстурами.
Windows/MSVC, GPU и Dota здесь НЕ запускались; вид в реальной игре не проверен.
ASan/UBSan не применялись из-за отсутствия библиотек.

Файлы установленной игры не читались/не изменялись. В папку игры ничего не копировать.
GitHub main не менялся. Приоритет README-ESP4 над старыми README.
Если вид ещё не соответствует прежнему — прислать прежний скриншот для точного сравнения,
а не менять HUD вслепую. Если пропало ESP — Copy ESP diagnostics, полный отчёт с hero[i].
