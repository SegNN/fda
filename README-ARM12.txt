ARM12 — исправление ложной блокировки Burning Spear self

Патч поверх полного ARM10 либо ARM10 с патчем ARM11. Это НЕ полный проект.
Закройте игру и старую DLL. Распакуйте ZIP в корень проекта с заменой файлов.
Запустите build.bat. Маркер сборки/меню: ARM12. При ошибке сборки не используйте старую DLL.
Файлы установленной игры не изменяются. Изменения GitHub не опубликованы.

Исправлено: точный modifier_huskar_burning_spear_self больше не считается
входящим DoT по подстроке burning. Проверен ваш набор blood_magic + item_armlet
+ burning_spear_self. Реальный burning_spear_debuff не исключён из проверки.
Добавлена строка danger: lastCheckedAt / hero / matched. Она показывает последнее
выполнение проверки модификаторов, а НЕ обязательно текущий кадр: более ранняя
проверка меню/выделения/инвентаря может остановить выполнение до неё.

Сохранены исправления ARM11: singleton selection с точным index или полным handle,
защита от stale serial и отчёт кандидатов; общий HP Y=-9 и red extra +6 отдельно.

Ограничения: это модуль по порогу HP, НЕ предсказатель входящего урона.
Следующий удар/тик, реальный урон после сопротивления и безопасное окно не рассчитываются.
Оставшаяся проверка опасных названий — консервативная эвристика, не измерение урона.
Не гарантирует выживание, переключение за один серверный тик или работу при любом DoT.
При прерывании цикла Armlet может остаться выключенным: проверьте вручную.
Все функции Melonity НЕ реализованы.

Проверяйте сначала только в демо. После запуска закройте меню на 2–3 секунды,
потом скопируйте полный отчёт ARM12 Armlet: current, lastClosedMenu, selection,
danger и строки героя. Не изменяйте случайно клавишу/слот, если они уже проверены.
Если lastClosedMenu сообщает о выделении, используйте строки candidate для диагностики;
это отдельная причина, которую правка self-модификатора не устраняет.

Тесты: Linux mock/portable без ASan/UBSan; реальный код адаптера на искусственных
памяти и Windows-вызовах. Полная сборка MSVC, ввод в Dota и матч НЕ проверены.
