FDA ARM14 — read-only диагностическая база параметров урона

Это полный исходный проект для продолжения разработки, НЕ полная копия Lotus/Melonity.
Распаковать FDA-ARM14 в НОВУЮ папку проекта, запустить build.bat.
Нужны MSVC x64, C++ и Windows SDK. Готовой DLL нет. При ошибке сборки старую DLL не использовать.
Файлы установленной Dota не читаются и не изменяются этим этапом разработки.
Readers внутри проекта читают память запущенного процесса; SDK диагностика не пишет в неё.
GitHub не обновлён. Новый визуальный дизайн в этой версии не создавался.

НОВОЕ:
- src/damage_probe.h: отдельный ограниченный read-only reader.
- src/damage_probe_catalog.inc: 1455 scalar candidate fields для 915 классов модификаторов.
- Источник смещений сверён с публичным git blob b768ef6754870ad27b06048a8afa8b40cccfc3e7.
  Это статический публичный дамп, НЕ resolver текущего schemasystem и не live-верификация.
  Ссылки/версии/ограничения: DAMAGE-PROBE-SOURCES.json.
- Runtime класс сопоставляется точно. Проверяются parent full handle, serial/index до/после;
  каждое поле читается дважды; неизвестные/нестабильные/NaN значения не подменяются нулём.
- В Копировать диагностику Armlet добавлен damageProbe. Автоматическое наблюдение работает
  при включённом модуле Armlet и подтверждённом локальном кадре, в том числе с открытым меню.
  Не больше 5 снимков за игровую секунду; максимум 6 модификаторов и 8 полей на объект.
  Это ограниченный диагностический отчёт, не полный дамп каждого эффекта.
- liveOffsetsVerified=0 и predictionReady=0 намеренно остаются нулём.
  Stable/readable/plausible НЕ означает корректное live-смещение или финальный урон.
- В базовом CDOTA_Buff offsets previousTick/thinkInterval НЕ разрешены: они остаются unknown.
  Где есть derived tick_interval — выводится сырое поле, но оно не считается временем до урона.
- Armlet НИКОГДА не принимает решение по значениям damage_probe; алгоритм ARM13 сохранён.
  ДоT не отменяет уже начатое ON, но новый OFF под распознанным DoT остаётся запрещённым.
  Нет предсказания смертельных атак/снарядов/тиков. Нет гарантии выживания.
- Первая причина Fault, native HP Y=-9, selection fixes и self-модификатор сохранены.

ПРОВЕРКА:
16 Linux mock/portable групп без ASan/UBSan. Reader проверен на Viper/Armlet,
неизвестном классе, отсутствующих полях, stale serial/parent, меняющемся объекте,
NaN/нестабильных значениях и ограниченном отчёте. Production Armlet adapter
проверяет попадание candidate damage в реальный formatter диагностического отчёта.
Полная MSVC/Windows/D3D11/live Dota НЕ проверены.
