FDA 0.5.5 / HUD8 — пустые кружки, HP, диагностика Armlet

Установка: весь архив в НОВУЮ папку -> build.bat, MSVC x64 / C++ / Windows SDK.
Маркер сборки и меню HUD8. Старый баннер HUD5 исправлен.
Не использовать старую DLL при ошибке; ничего не копировать в установленную папку игры.

Эффекты:
Пустые кружки от модификаторов без подходящей иконки больше не создаются.
Оставшиеся иконки заново центрируются по числу действительно отображаемых групп.
Это НЕ утверждение, что любой неизвестный модификатор внутренний или не существует.
Он остаётся в полном снимке и в диагностике; в UI нет ложного дополнительного баффа-заглушки.
Само наличие иконки тоже не доказывает, что модификатор видим в штатной панели Dota.
Группировка по точному имени из HUD7 сохранена. Без raw names нельзя объявить две разных
сущности одним эффектом или безопасно суммировать их счётчики.
Счётчик по центру, время снизу, ring remaining/duration; до восьми групп.
Фильтр касается только отображения: полный список для Armlet НЕ фильтруется и проверки
DoT/неизвестных данных не обходятся.
Copy ESP diagnostics теперь содержит до 16 исходных имён модификаторов каждого героя,
stackCount, duration, expires и clock. Буфер увеличен до 32KiB. Это ограниченный отчёт,
не полный дамп всех модификаторов клиента. Неотображаемые модификаторы также включены.

HP:
Текст опущен на 4px относительно HUD7 (центр anchorY -24 вместо -28).
Размер 14px, центрирование по glyph ink bounds сохранено. Только текст, НЕ новый HP-бар.
Перед проверкой HeroInfo -> Сбросить сдвиги HP; прежние profile X/Y могут мешать.
Точный native HUD rect из Dota не извлекается: используется projected health-bar anchor.
Привязка в живой Dota не проверена. При другом масштабе/камере может нужна калибровка.

Armlet:
Нельзя честно назвать его исправленным для вашего клиента без причины блокировки.
Добавлена кнопка Huskar -> Копировать диагностику Armlet: enabled/confirmed/key/slot,
threshold/bind, localFrame/observedOnly/controller/source/reference scan и данные героев.
Последний статус при ЗАКРЫТОМ меню сохраняется отдельно: открытое меню больше не скрывает
эту предыдущую причину. При отсутствии вызовов Tick будет Not sampled with menu closed:
это диагностическое отсутствие, а не готовность модуля.

Что прислать:
Включить настроенный модуль, закрыть меню на 2–3 секунды, снова открыть настройки Huskar,
нажать Копировать диагностику Armlet и вставить текст. Дополнительно Copy ESP diagnostics
во время Burning Spear для имён обоих исходных модификаторов.
Не нужно повторять наугад клавиши или выключать проверки.
Текущий модуль: порог HP, подтверждение OFF -> ON, проверка данных и пауза цикла.
Он НЕ предсказывает входящий урон и не является полноценным универсальным auto-armlet.
Распознанный Burning Spear debuff/другой опасный DoT блокирует цикл по текущей реализации.
Тоггл самого Burning Spear/counter не трактуются как урон (сохранено из предыдущей версии).
Если HP 538 или 565, а порог 350, цикл не должен начинаться только по порогу.
Без локального игрока, проверенного инвентаря/полного списка buffs автонажатий нет.

Проверки:
14 Linux mock/portable групп без ASan/UBSan; дополнительный тест сохранения прошлой причины
Armlet при открытии меню. Actual ImGui geometry CPU-preview проверен на синтетических данных.
MSVC, полноценное приложение Windows, D3D11/GPU и живой матч НЕ проверены.
C4244 у ternary размера шрифта исправлен явными float literals, но новый MSVC лог не получен.
Косметика GC отключена. GitHub не изменён. Только исходники проекта; файлы игры не трогались.
README-HUD8 имеет приоритет над прежними README. Уровни Huskar fallback сохраняются из HUD7.
