FDA 0.5.5 / ESP2 — исходники, не готовая DLL

Порядок проверки:
1. Закрой Dota и программу, использующую старую DLL.
2. Распакуй ВЕСЬ архив в новую папку, не поверх старого проекта.
3. Запусти build.bat. Нужны MSVC x64 (Desktop development with C++) и Windows SDK.
4. При успешной сборке результат — build\obsdota2.dll. Если сборка упала, старую DLL не используй.
5. В меню должна быть надпись FDA 0.5.5 / ESP2. Сначала проверяй в демо или локальном лобби.
6. Включи ESP героев и рамки, закрой меню и посмотри на героя в поле камеры.

Что изменено относительно CTRL1:
- Базовое мировое ESP не зависит от наличия локального контроллера: рамки, имена, HP.
- Когда свой игрок неизвестен, показываются абсолютные команды Radiant / Dire / Neutral,
  а не выдуманное деление на союзников и врагов. local frame остаётся unavailable.
- При отсутствии локальной идентичности автофункции заблокированы; туман/свечение не изменяются.
- Индекс сущности 0 теперь сканируется. Классификация поддерживает проверенное имя designerName
  с проверками обратной ссылки и полной версии handle; указатель строки не обязан быть выровнен.
- Переключатель рамок теперь используется и в обычном ESP героев.
- Неправильный глобальный адрес контроллера отключён: на скриншоте CTRL1 его RTTI — C_DOTAGamerules.
- Добавлены счётчики классифицированных/проецируемых сущностей, строки матрицы и копирование отчёта.

Если ESP всё ещё отсутствует:
В Data diagnostics нажми Copy ESP diagnostics и вставь текст отчёта в чат.
Также пришли скриншот героя с закрытым меню. Не нужно повторять git-команды.
World view: observed-only означает режим без своего игрока, а не успешное восстановление контроллера.
Units/Heroes показывают прочитанные сущности; Projected units — прошедшие проекцию.
WORLD ESP: N drawn — число нарисованных сущностей, не доказательство корректности камеры.
Matrix: plausible проверяет только форму значений, не правильность адреса/матрицы камеры.

Ограничения:
13 групп Linux mock/portable тестов пройдены, включая реальные ImGui-вершины базового ESP.
Тесты используют имитацию памяти/Windows и проекцию. MSVC, GPU и запущенная Dota здесь НЕ проверены.
ASan/UBSan в этом прогоне не использовались (библиотеки недоступны).
Это исправление блокировки базового ESP, НЕ подтверждённый ремонт всех функций чита.
Поиск своего игрока остаётся нерешённым, если сканер снова видит controllers=0.
Косметика/Steam GC по-прежнему отключены: предметы не добавляются, разблокировка и надевание
в матче не реализованы. Auto-accept без GC-сигнала готовности не работает — принимай вручную.
Старые README-* и QA-CTRL1 описывают прошлые версии; для этого архива приоритетен README-ESP2.
Файлы установленной игры не читались и не изменялись. Ничего из архива не копировать в папку игры.
GitHub main не менялся: архив — локальная версия на основе 40a11e81b0ba467b4980590d7a61dcfda01f87fe.
