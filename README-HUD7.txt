FDA 0.5.5 / HUD7

Установка: весь архив в НОВУЮ папку, build.bat (MSVC x64, Windows SDK, C++).
При успешной сборке build\obsdota2.dll; маркер меню HUD7. При ошибке не использовать старую DLL.
Не копировать файлы в установленную папку Dota. Сначала проверить в демо.

Уровни способностей:
- Сегменты maxLevel снизу, без чисел уровня. Изученные светлые, пустые серые,
  высота 5px вместо почти чёрных 4px. Неизученные иконки затемнены.
- HUD6 не рисовал сегменты при maxLevel=0. При неизвестном runtime max для именованных
  способностей Huskar используется точный опубликованный максимум Valve:
  inner_fire=4, burning_spear=4, berserkers_blood=4, life_break=3, blood_magic=1.
- Корректный runtime максимум/override приоритетнее. Текущий уровень НЕ выдумывается.
  Если текущий уровень выше опубликованного максимума, этот fallback не применяется.
  Остальным способностям произвольные 4/3 сегмента не назначаются.
- Copy ESP diagnostics теперь содержит ability[hero,index]: name, level, max.
  Если у другого героя сегментов нет, нужен HUD7-отчёт, а не угадывание максимума.

Эффекты:
- Один кружок на ТОЧНОЕ имя модификатора. Повторные экземпляры объединяются в группе.
- В центре сумма стаков; нестакующий экземпляр со stackCount=0 считается одним эффектом.
  До 999 включительно точное число, выше — 999+.
- Под кружком время: секунды с десятыми; длинные эффекты m:ss/h.
  Для разных сроков в одной группе показано время до конца ПОСЛЕДНЕГО экземпляра,
  не утверждается, что все слои одновременно исчезнут. По истечении слои отфильтровываются.
- Обводка оставшееся время / duration выбранного последнего экземпляра.
- Неизвестное время = ?, постоянный эффект без времени. Нет выдуманного таймера.
- Круглая маска текстур сохранена; диаметр 30px, промежутки 10px, место под временем.
- Подбор иконок по точному имени/известным суффиксам, а не произвольным обрезаниям строки.
  Нет ресурса — тёмный нейтральный кружок с количеством, не чужая картинка.
- Зелёные Flask/Tango/Clarity, несколько известных DoT красные. Неизвестная полярность
  нейтральная: универсальный isDebuff здесь не прочитан и не выдумывается.
- До 8 разных групп в ряду, effectsTimedOnly сохранён. Сортировка по имени стабильна.

Число HP:
- Штатный бар игры не рисуется и не изменяется. Только белые цифры с обводкой.
- Размер 14px; позиция центрируется по реальным видимым контурам цифр (glyph bounds),
  а не по line height/асценту шрифта. Положение округляется до пикселя.
- Калибровка центра относительно projected health-bar anchor: X +3px, Y -28px.
  HeroInfo X/Y offsets сохраняются; прежние пользовательские смещения тоже сохраняются.
- Это исправление геометрии текста, НЕ подтверждённое распознавание штатного HUD-rect.
  При другой камере/масштабе интерфейса может понадобиться X/Y калибровка.
  Точная привязка к бару в живой игре здесь не проверена.

Другие функции:
Фиксированные ряды под героем, статусы/иллюзии, observed INVIS сохранены из HUD6.
Armlet в этом патче НЕ менялся: обязательные проверки данных/локального игрока сохранены.
Инструкция Armlet в README-HUD6 и в меню Huskar. Нельзя считать ESP признаком готовности
автоматизации: localFrame/inventoryRead/buffsRead должны быть подтверждены.
Косметика/Steam GC остаются отключены. GitHub main не изменён.

Проверено: 14 Linux mock/portable групп без ASan/UBSan, actual ImGui mesh preview.
Резервный максимум Huskar и runtime override проверены в реальном ReadAbilities на MOCK памяти.
Проверены объединение стаков, последний expiry, unknown clock, expiry filtering,
центрирование 440 с точностью до округления 0.5px. Не живой матч и не готовая DLL.
MSVC, полный Windows/D3D11/GPU и реальная Dota НЕ тестировались.
Файлы установленной игры не читались/не изменялись: только исходники проекта и публичные источники.
