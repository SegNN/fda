СОВЕТНИК — Прочее / Misc -> Draft advisor:
- Теперь рекомендация: герой, позиция (1-5), ТОП/НИЗ/МИД, конкретный союзник на линии.
- Автоматическое считывание пиков включено по умолчанию, но ЭКСПЕРИМЕНТАЛЬНОЕ.
  Читает PlayerResource без необходимости появления назначенного героя; полный read-only
  native adapter и bounded reader добавлены. Нужны найденный собственный контроллер и
  единственный exact C_DOTA_PlayerResource из существующего entity scan.
  Проверяются RTTI, full handle/serial/backlinks, local flag, player ID, stable field reads,
  vector bounds, известные hero IDs, normal 5v5 team bounds, отсутствие дублей.
  Два независимых согласованных снимка с интервалом минимум 250ms.
  При repick/новых данных прежние рекомендации не удерживаются до подтверждения.
- СМЕЩЕНИЯ из статического публичного дампа, НЕ runtime schema resolver текущего клиента.
  offsetsLiveVerified=0. Даже согласованные/правдоподобные чтения не доказывают live-версию.
  DRAFT-READER-SOURCES.json содержит точные источники/поля/ограничения.
- Если PlayerResource не разрешён, fallback читает состав из verified Frame текущего матча.
  Этот источник НЕ видит pre-spawn draft; в UI явно помечен отдельно.
- Если нет ни того, ни другого, никакие пики не выдумываются. Выключить Auto и заполнить
  четыре союзных героя вручную. Команда Radiant/Dire для ручного режима выбирается явно.
- Исключает прочитанные уже выбранные героями игроков варианты (включая соперников, когда
  их IDs доступны). Bans/вражеские матчапы и winrate не рассчитываются.
- Если свой герой уже выбран и прочитан, советник не предлагает заменить его: показывает
  позицию/линию/напарника для текущего героя. Нет приказов выбора героя или движений.
- Ввод роли союзника 1-5 фиксирует её; «Предложить роль» даёт предположение по bot weights.
  Моя роль может быть Auto или задана явно. Конфликт одинаковых позиций -> нет решения.
- Пары 1+5 и 3+4; мид одиночный. Radiant: carry bottom/offlane top; Dire зеркально.
- Если союзники не сообщили роли, это их ПРЕДПОЛАГАЕМОЕ распределение, не реальные планы.
  Данные OpenHyperAI MIT pinned cb814c6c8dc51ed08045d6efd9f4a48147992711.
  Перебор распределений максимизирует weights и небольшой pair control/damage бонус.
  Не «лучший герой в любой игре», не гарантированный контрпик или оценка победы.
