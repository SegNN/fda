FDA 0.5.4 — Kill helper (экспериментальные исходники)

НОВОЕ
Хелпер показывает базовую оценку, какой изученной способностью может хватить
урона для врага ПОД КУРСОРОМ. Это отдельный read-only HUD, не автонажатия.
Бой > Kill helper: включить (по умолчанию ON), запас HP (30), фильтр изученных
спеллов с моделью. Такой же переключатель есть в настройках Kill Stealer.
Закрой меню и наведи курсор на видимого вражеского героя. Если нет подходящей
цели, панель не появляется. Она не выбирает ближайшего/самого слабого врага
и не утверждает, что знает, с кем ты сейчас дерёшься.

ЧТО ПОКАЗЫВАЕТ
Название, уровень, оценка урона после магического сопротивления/брони,
урон минус HP (положительное число — числовой запас), отдельный статус:
по базе хватает, ниже HP + запас, нет маны, вне базовой дальности,
не готов/данные недоступны, известная защита/запрет, неизвестная защита.
Условно достаточные варианты идут первыми. Цвет янтарный, не зелёная гарантия.
Формулы: magical = raw*(1-resist); physical = raw*(1-0.06*A/(1+0.06*abs(A)));
pure = raw. Рекомендация требует damage >= HP + выбранный запас, читаемые
списки модификаторов и состояния, видимость, ману, готовность и дальность.
Даже при статусе «По базе хватает» убийство не гарантируется.
Неизвестные характеристики не превращаются в нули. Без подтверждённой защиты
показывается арифметика (если возможна), но НЕ достаточность для добивания.

ТОЧНОЕ ПОКРЫТИЕ: 17 БАЗОВЫХ ОДНОРАЗОВЫХ МОДЕЛЕЙ
Lina: Dragon Slave, Light Strike Array, Laguna Blade.
Lion: Earth Spike, Finger of Death (БЕЗ накопленных убийств).
Zeus: Arc Lightning, Lightning Bolt (БЕЗ Static Field).
Luna: Lucent Beam. Sven: Storm Hammer (БЕЗ удара/бонуса Scepter).
Ogre: Fireblast (ОДНО попадание, БЕЗ multicast).
Pudge: Meat Hook (обычная базовая версия, БЕЗ Flayer's Hook/Shard).
Queen of Pain: Shadow Strike (только стартовый урон), Scream of Pain, Sonic Wave.
Vengeful Spirit: Magic Missile, Wave of Terror, Nether Swap.
Это НЕ все способности этих героев и НЕ все герои. Остальные спеллы —
«Нет модели урона» при отключённом фильтре, а не выдуманный расчёт.
Базовая дальность Scream of Pain — радиус, остальные — значение cast range;
ширина/конус/препятствия/возможность попасть не определяются.
Уровень берётся из читаемого Frame, сопоставление по engine-имени, не по QWER.

РУЧНАЯ ОЦЕНКА ДЛЯ НЕПОДДЕРЖИВАЕМОГО СПЕЛЛА
В Kill Stealer привяжи профиль к текущему герою, выбери реальный слот,
тип, raw damage и дальность. Для хелпера не нужно включать Kill Stealer,
подтверждать quickcast или держать бинд. Строка помечается «ручной».
Ручной профиль используется только если нет встроенной модели этого спелла.
Смена героя прекращает применение чужого ручного профиля.
Для моделируемой способности с нестандартным аспектом встроенная оценка
остаётся только базовой; автоматического определения аспекта здесь НЕТ.

ВАЖНЫЕ ОГРАНИЧЕНИЯ
Каталог — закреплённый снимок KV, не прочитанный окончательный урон текущей
установки Dota. Патч может изменить цифры. Таланты, аспекты, Scepter/Shard,
усиление заклинаний, барьеры/снижение урона, многие защитные механики,
стаки Finger, multicast, DoT/каналы, регенерация, полёт/прицеливание НЕ учтены.
Защитный список консервативный и НЕ полный. Распознавание модификаторов
по-прежнему экспериментальное: неизвестный список не означает «защиты нет».
Готовность/offsets/layout требуют проверки в настоящем клиенте.
Хелпер никогда не вызывает SendInput/SetCursorPos и не запускает авто-KS.
Существующий ручной автокаст из 0.5.3 остаётся отдельным, OFF по умолчанию.

СБОРКА / ПРОВЕРКИ
Полностью распаковать в НОВУЮ папку, build.bat; MSVC x64 + Windows SDK.
Это полный source-проект с vendor/assets/injector source, НЕ готовая DLL.
Сначала демо/локальное лобби, не рассчитывать на оценку как гарантию.
Linux: tests/run-effects-tests.py (g++ + ASan/UBSan); Windows portable logic:
tests/run-effects-tests.bat из x64 Native Tools Command Prompt.
QA-RESULTS.txt описывает реальные выполненные mock-тесты, не live Dota.
preview/kill-helper-* — реальный ImGui на СИНТЕТИЧЕСКИХ данных поверх старого
скриншота, не доказательство работы в матче. Все варианты визуально проверены.
Нет проверки MSVC/Windows ABI, live чтения/урона/Armory/античита.
